What Is voidtools Everything?

Created by David Carpenter under the banner of voidtools, Everything is a desktop search utility designed exclusively for Microsoft Windows (supporting Windows XP through Windows 11 and Windows Server editions). Unlike traditional search engines that slowly scan directory trees file-by-file, Everything hooks directly into file system metadata to provide real-time results as you type.

When you open Everything for the first time, you are greeted by an uncluttered, responsive interface. Typing a single letter instantly populates every matching filename on your storage drives. As you continue typing, the result list narrows in real time without lag or system stuttering.

To appreciate why Everything outperforms native Windows Search by order of magnitude, it helps to understand its underlying architecture.

1. NTFS Master File Table (MFT) Indexing

Most search tools crawl disk directories line-by-line, opening each folder to query file attributes. Everything bypasses this bottleneck on NTFS formatted drives by directly reading the Master File Table (MFT)—a hidden database file maintained by the NTFS file system that contains attributes, sizes, names, and sector locations for every file on the partition.

2. USN Journal Tracking

Once the initial MFT index is created, Everything stays updated using the Windows Update Sequence Number (USN) Change Journal. Whenever a file is created, modified, renamed, or deleted, Windows logs the event in the USN Journal. Everything monitors this stream, ensuring your index stays current without needing background disk scans.

3. Non-NTFS and ReFS Support

While MFT indexing provides maximum speed for local NTFS drives, Everything also indexes ReFS volumes, FAT32/exFAT drives, mapped network shares (via scheduled folder indexing or ETP/FTP connections), and external USB devices.

Masterclass: Advanced Search Syntax & Regex Syntax

While simple keyword searching works out of the box, Everything's true power lies in its advanced syntax and regular expression (regex) capabilities.

Common Search Operators

  • Wildcards: Use * to match multiple characters and ? to match a single character.
  • Example: *.png finds all PNG images.
  • Exact Phrases: Enclose search terms in quotes.
  • Example: "Project Alpha Specification"
  • Boolean Operations: Combine terms using AND (space), OR (|), and NOT (!).
  • Example: video | audio !mp3 finds video or audio files, excluding MP3s.
  • Path Filtering: Use path: to limit queries to specific directory structures.
  • Example: path:d:\projects\2026
  • Extension Filtering: Use ext: followed by file extensions separated by semicolons.
  • Example: ext:docx;pdf;txt

Attribute and Size Modifiers

Everything allows filtering by precise file parameters, including creation dates, access dates, and file sizes:

  • Size Filters: size:>500mb, size:1gb..5gb, size:empty
  • Date Filters: dm:today (Date Modified today), dc:lastweek (Date Created last week), dm:2026-01-01..2026-03-01
  • Duplicate Finders: dupe: or sizedupe: locate duplicate filenames or matching file sizes across drives.
# Find all PDF files modified in 2026 larger than 10MB inside C:\Work
path:C:\Work ext:pdf dm:2026 size:>10mb

# Find duplicate video files across all indexed drives
ext:mp4;mkv;avi dupe:name

Regular Expressions (Regex)

Enable regex by pressing Ctrl + R or prefixing your search with regex:.

  • Match Pattern Example: regex:^[0-9]{4}_[a-z]+ finds files starting with four digits followed by an underscore and lowercase letters (e.g., 2026_report.txt).

Remote Indexing: HTTP, ETP, and Command-Line Interface

Everything goes beyond desktop search by offering server utilities and command-line execution.

1. Built-in HTTP Server

By enabling the HTTP server in Options > HTTP Server, Everything transforms into a web application. You can host an internal file search portal accessible from any device on your local network (LAN), including smartphones, iPads, or Linux workstations.

2. ETP / FTP Server

Everything includes an ETP (Everything Transfer Protocol) server based on FTP. This enables multiple remote client instances of Everything to connect to a centralized master index hosted on a home server or corporate SAN.

3. Command-Line Interface (CLI)

For system administrators and automated scripts, voidtools provides a dedicated CLI utility (es.exe). You can query Everything directly from PowerShell or Command Prompt:

# Query Everything via PowerShell CLI for large log files
es.exe -path "C:\Logs" -size +100MB -sort date-modified-desc

Essential Setup Steps for 2026

Follow these recommendations to get optimal performance from Everything on modern Windows operating systems:

  1. Download the Official Installer: Always download directly from voidtools.com or verified repositories. Select the 64-bit installer or portable version.
  2. Install Everything Service: Choose "Install Everything Service" during setup. This allows the program to read NTFS MFT indexes without needing UAC administrator escalation every time it launches.
  3. Pair with Everything Toolbar: For seamless Windows 11 integration, pair Everything with the open-source EverythingToolbar utility. This replaces the default, slow Windows Search bar on your taskbar with Everything's instant indexing backend.
  4. Set Up Custom Hotkeys: Map Toggle Everything Window to Alt + Space or Win + Shift + F for quick desktop access.

Pros & Cons

Pros

  • Unrivaled Search Speed: Instant results across millions of files.
  • Minimal Resource Usage: Low CPU utilization and minimal memory consumption.
  • Extensive Customization: Supports Regex, custom bookmarking, CLI automation, and filters.
  • Powerful Remote Features: Built-in HTTP and ETP/FTP server deployment.
  • Privacy Focused: Operates locally on your device without sending index telemetry to cloud servers.

Cons

  • Filename Centric: By default, content indexing (searching inside text/PDF files) is slower than filename indexing.
  • Windows Exclusive: Not natively available on macOS or Linux (though accessible via web browser through the HTTP server).

Final Verdict

In an era where desktop operating systems are increasingly bloated with cloud integrations and heavy background indexes, voidtools Everything remains a lean, highly reliable file search tool. It transforms file management from a tedious task into an effortless workflow. If you want instant file retrieval on Windows, Everything remains an essential download.
