Created by David Carpenter of voidtools, Everything is a desktop search engine specifically designed for Windows operating systems. Unlike traditional search utilities that crawl through directories opening every file to index contents, Everything focuses primarily on file and folder names and system metadata.

When launched for the first time, Everything generates an index of all local storage volumes. A fresh index of a drive containing 500,000 files takes roughly 0.5 seconds. Once indexed, searching happens literally as you type—character by character, in real-time.

How It Works: The Magic of NTFS MFT

The secret behind Everything’s unbelievable speed lies in how it interfaces with the Windows NTFS file system. Instead of scanning files using standard Windows APIs, Everything requests administrative access to read the Master File Table (MFT) and the USN (Update Sequence Number) Change Journal directly from your storage drives.

  1. Initial Indexing: The MFT is a hidden database on every NTFS volume that stores locations, names, and metadata of every file. Everything parses this database directly at low-level hardware speeds.
  2. Live Updates: When files are added, modified, or deleted, Windows logs the action in the USN Change Journal. Everything hooks into this journal to update its internal index live without needing to re-scan the hard drive.

Core Features That Make Everything Unbeatable

1. Zero-Latency Filtering

Whether searching through 50,000 photos or 5,000,000 system files, results filter instantaneously with every keypress. There is zero indexing lag or typing delay.

2. Lightweight Resource Management

A typical installation occupies around 5 to 10 MB of disk space. When running silently in the system tray, it consumes approximately 15 MB to 40 MB of RAM depending on the total number of files indexed (roughly 1 MB of RAM per 20,000 files).

3. Comprehensive File Filtering & Sorting

You can filter search queries by file extension, folder status, modification date, file size, audio tags, video resolutions, and custom macros.

4. Native HTTP & ETP/FTP Servers

Everything includes a built-in web server. Enabling this feature lets you access your desktop files remotely from a web browser on your phone, laptop, or tablet across your local Wi-Fi or VPN network.

5. Multi-Language & Portable Execution

Everything can run directly from a USB flash drive as a fully portable application without requiring installation or altering Windows system registries.

While simply typing a keyword works instantly, the real power of Everything unlocks when you leverage wildcards, modifiers, and search functions.

Basic Search Modifiers

  • word1 word2 : Searches for files containing both word1 and word2 (AND operator).
  • word1|word2 : Searches for files containing either word1 or word2 (OR operator).
  • !word1 : Excludes results containing word1 (NOT operator).
