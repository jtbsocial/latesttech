2. What is Voidtools Everything? Core Architecture Explained

At its core, Everything is an ultra-fast desktop search engine designed specifically for Windows environments. Unlike traditional indexing software that opens each file to build a deep text content index, Everything focuses on hyper-fast file and folder name location.

+-----------------------------------------------------------------------+
|                         Windows OS Storage                            |
|  +-----------------------------------------------------------------+  |
|  |                  NTFS Master File Table (MFT)                   |  |
|  +-----------------------------------------------------------------+  |
+-----------------------------------------------------------------------+
                                   | (Direct Binary Read)
                                   v
+-----------------------------------------------------------------------+
|                      Voidtools Everything Engine                      |
|  - Reads MFT Journal in Memory (< 30 MB RAM)                          |
|  - Updates Real-time via USN Change Journal                           |
|  - Instant Keyword & Regex Matching (< 0.01 Seconds)                  |
+-----------------------------------------------------------------------+

How It Achieves Instant Search Speeds

  1. Direct MFT Parsing: For NTFS formatted drives, Everything reads the drive's Master File Table (MFT) directly at launch. Instead of traversing folder by folder, it parses the filesystem metadata map in raw binary.
  2. USN Change Journal Monitoring: To stay updated in real-time without re-scanning, Everything hooks into the Windows Update Sequence Number (USN) Change Journal. When a file is created, renamed, or deleted anywhere on your system, the index updates instantly.
  3. Minimal Memory Footprint: An index containing over 1,000,000 files typically consumes less than 30 Megabytes of RAM and negligible disk footprint, making it ideal for high-performance workstations and legacy hardware alike.

7. Step-by-Step Setup & Everything Server Deployment

Step 1: Downloading & Installation

  1. Visit the official website at voidtools.com.
  2. Download the latest installer (x64 or Portable version available).
  3. During setup, select Install Everything Service (recommended) so the app runs with minimal elevated administrative prompts during daily use.

Step 2: Basic Configuration

  1. Launch Everything. The main window will pop up.
  2. Go to Tools -> Options -> Indexes.
  3. Verify your fixed NTFS volumes are checked for automatic indexing.
  4. (Optional) Under Folder Indexing, add network shares or mapped NAS drives if required.

Step 3: Enabling Remote Everything Server

  1. Go to Tools -> Options -> HTTP Server.
  2. Check Enable HTTP Server.
  3. Specify a port (e.g., 8080) and set up administrative username and password credentials for secure access.
  4. You can now access your file search index remotely from any web browser on your network!
