⚡ Executive Summary / Key Takeaways

Unlike traditional search engines that crawl file contents, Everything directly reads the Master File Table (MFT) and USN Journal of NTFS volumes to instantly locate files and folders by name.

  • Instant Indexing: Indexes up to 1,000,000 files in under 1 second upon initial launch.
  • Minimal Resource Footprint: Operates on less than 15 MB of RAM and minimal CPU overhead.

  • Advanced Search Capabilities: Supports regular expressions (regex), boolean operators, audio/video metadata filters, and command-line interfaces.
  • Built-in Server Capabilities: Includes native HTTP, FTP, and ETP servers to allow remote file searching across local area networks.

Created by David Carpenter under the banner of voidtools, Everything is an administrative desktop search utility built specifically for Microsoft Windows. First released over a decade ago and continually refined through major updates like the 1.4 stable branch and 1.5 alpha preview releases, Everything answers a simple question: What if searching your 4TB storage array felt as fast as typing a single letter?

When you launch Everything for the first time, it does not scan every individual document or crawl inside your text files. Instead, it bypasses the operating system's slow file crawler and communicates directly with the lower-level file system structure of your drives.

|                         EVERYTHING ARCHITECTURE                       |
+-----------------------------------------------------------------------+
|  [ User Query ] ---> [ Everything RAM Index ] ---> Instant Results    |
|                                  ^                                    |
|                                  | (Direct Low-Level Read)            |
|                     [ NTFS Master File Table (MFT) ]                  |
|                     [   USN Change Journal Logs    ]                  |

How Everything Achieves Millisecond Speed

  1. Direct MFT Access: On NTFS formatted drives, Everything directly parses the Master File Table (MFT), a special system file where Windows stores metadata about every file and directory.
  2. USN Change Journal Integration: Once the initial index is built, Everything monitors the Update Sequence Number (USN) Change Journal. When a file is modified, moved, or deleted, Windows logs it in the USN Journal, and Everything updates its internal index instantly without rescanning the disk.
  3. Memory-Centric Indexing: File names and directory paths are cached entirely in system memory (RAM). Searching 1,000,000 files requires roughly 12 to 15 MB of RAM, allowing instantaneous regex matching and sorting.

Key Features Breakdown (2026 Edition)

1. Minimal Installation & Zero Overhead

Everything installs in seconds via a tiny setup file (<5 MB) or can be run as a portable executable directly from a USB flash drive. It offers full support for both 32-bit and 64-bit Windows environments, running silently in the system tray.

2. Live Real-Time File Monitoring

Unlike third-party search tools that require scheduled re-indexing, Everything registers changes the exact millisecond they occur. If a program saves an export file to a deep subdirectory, typing the name into Everything will display the file while the saving animation is still active in your editing app.

3. Integrated HTTP & FTP Server Options

Everything includes built-in server capabilities. You can enable the HTTP Server or FTP Server from the options menu, allowing you to access and search your primary PC's storage remotely from a laptop, tablet, or smartphone connected to the same local network.

4. Custom Filters and Syntax Support

From finding duplicate files to locating zero-byte logs or uncompressed video files, Everything supports extensive operators, functions, and regular expressions.

Mastering Everything Search Syntax: A Practical Field Guide

While simple queries like report2026.pdf work instantly, the real power of Everything lies in its advanced query modifiers and function calls.

Essential Operators & Wildcards

  • Spaces act as AND: report project 2026 finds files containing all three terms in any order.
  • OR Operator (|): jpg|png finds files containing either extension.
  • NOT Operator (!): !c: excludes items located on the C: drive.
  • Exact Phrase (""): "Annual Financial Report" searches for the exact phrase.
  • Wildcards (* and ?): vacation*.jpg matches vacation_01.jpg, vacation_hawaii.jpg, etc.

                 POWER USER SEARCH COMBINATIONS

1. Find Large Video Files on D: Drive
   Query: d: ext:mp4;mkv;avi size:>2gb

2. Locate Duplicate Audio Track Names
   Query: ext:mp3 dupe:name

3. Find Empty Directories
   Query: folder: empty:

Setting Up Remote Search with Everything Server

One of the most impressive hidden capabilities in Everything is its ability to serve as a lightweight network indexer. If you manage multiple desktop PCs, home servers, or NAS units running Windows, you can query all remote storage from a single client interface.

+-----------------------------------------------------------------------+
|                      REMOTE SERVER DEPLOYMENT                         |
+-----------------------------------------------------------------------+
|  [ Primary Media Server ]  <--- (Runs Everything HTTP/ETP Server)     |
|             |                                                         |
|             +---> [ Client PC 1: Everything ETP Index Client ]        |
|             +---> [ Client PC 2: Web Browser via HTTP Interface ]     |
+-----------------------------------------------------------------------+

Step-by-Step Configuration:

  1. Open Everything on the host computer.
  2. Navigate to Tools > Options > HTTP Server (or ETP/FTP Server).
  3. Check Enable HTTP Server.
  4. Specify a custom port (e.g., 8080) and create a secure username and password.
  5. Click Apply.
  6. From any machine or web browser on your network, navigate to http://<host-ip-address>:8080 to search the remote machine's drives with instant results.
