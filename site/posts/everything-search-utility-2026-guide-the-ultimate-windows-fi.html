The Frustration of Windows Search and the Rise of Everything

We have all experienced the excruciating delay of standard file searches in Microsoft Windows. You open File Explorer, type a filename into the top-right search box, and watch a sluggish green progress bar creep across the address bar. Minutes pass while your disk thrashes, only for Windows Search to report zero results or present an incomplete list of buried documents.

For power users, system administrators, developers, and digital archivists, native Windows Search has long been a notorious bottleneck. Enter Everything, the legendary freeware desktop search utility created by David Carpenter under the banner of voidtools.

Unlike traditional indexing tools that crawl every folder and open every document, Everything operates on a radically different principle. By reading raw file system metadata directly from the NTFS Master File Table (MFT), Everything can index over one million files on a fresh Windows installation in under one second.

Whether you are hunting for a mislaid PDF among terabytes of archival storage or searching across complex network shares, this guide breaks down everything you need to know about the Everything search engine in 2026.

To understand why Everything leaves alternative desktop search utilities in the dust, it is vital to analyze its underlying architectural mechanics.

1. Direct NTFS Master File Table (MFT) Access

Standard file search utilities rely on Windows Indexing Services, which scan files line by line, opening documents and analyzing text contents. This creates heavy disk reads, high CPU overhead, and massive background database overhead.

In contrast, Everything connects directly to the NTFS Master File Table (MFT). The MFT is a hidden system database built into every NTFS-formatted drive that stores the filename, size, timestamp, and physical location of every file on the disk. Instead of walking through the directory tree, Everything loads the entire MFT into system memory upon launch.

2. Real-Time Tracking via USN Change Journals

When you create, delete, rename, or move a file, Windows records the modification in the NTFS Update Sequence Number (USN) Change Journal. Everything monitors this lightweight stream continuously. As a result, file changes are mirrored instantly in your search window without requiring background drive rescans.

3. Ultra-Lean Memory Allocation

Despite keeping file paths for millions of items in RAM, Everything uses an exceptionally optimized C++ structure. A typical storage drive containing 1,000,000 files requires only approximately 45 MB of RAM and roughly 5 MB of disk space for its index database.

Built-in HTTP and FTP File Servers

One of the most impressive hidden capabilities in Everything is its built-in web and FTP server engine. By toggling a single setting in the options menu, you can transform your local desktop index into an accessible web interface across your local area network (LAN):

  • HTTP Server: Search and download files from your primary PC using any web browser on an iPad, smartphone, or secondary computer.

While early versions focused strictly on file names, current builds allow users to selectively index expanded properties, including:

For developers and system administrators, voidtools provides a standalone Command-Line Interface tool (es.exe) alongside a C-compatible SDK (Everything.dll). Power User Masterclass: Search Syntax & Operators

To unlock the true power of Everything, you must move beyond basic word searching. The software features a rich query language that lets you pinpoint files with mathematical precision.

1. Basic Operators & Wildcards

  • * matches zero or more characters. Example: report*.pdf matches report2026.pdf or report_final.pdf.
  • ? matches a single character. Example: image??.jpg matches image01.jpg.
  • Space acts as a logical AND. Example: vacation 2025 png finds files containing all three terms in any order.
  • | acts as a logical OR. Example: cat | dog finds files containing either term.
  • ! acts as a logical NOT. Example: !draft .docx finds .docx files that do not contain the word draft.

2. Size & Date Filters

Finding large files eating up drive capacity is effortless with size operators:
* size:>1gb – Displays files larger than 1 Gigabyte.
* size:10mb..50mb – Displays files between 10MB and 50MB.
* dm:today – Filters files modified today.
* dc:lastweek – Filters files created last week.

3. Path & Attribute Functions

  • path:c:\projects – Restricts search results exclusively to the C:\projects directory.
  • ext:jpg;png;webp – Filters results to display specific file extensions.
  • attrib:R – Locates read-only files.
  • dupes: – Identifies duplicate filenames across your drives.

4. Regular Expressions (Regex)

Toggle Regex mode (Ctrl + R) or prefix your query with regex: to run complex patterns:
* regex:^[0-9]{4}_doc – Matches filenames starting with a four-digit year followed by _doc.
* regex:[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,} – Scans filenames containing raw email address patterns.

Step-by-Step Guide: How to Install & Optimize Everything

Getting started with Everything takes less than two minutes. Follow these optimal setup steps:

Step 1: Download the Official Installer

Head over to the official voidtools download portal (voidtools.com). Download the latest 64-bit installer or portable edition. If you are setting up a managed machine, the Everything Service installation option is recommended so non-admin user accounts can search without UAC prompts.

Step 2: Configure Initial Indexing Settings

  1. Open Everything and navigate to Tools > Options.
  2. Under NTFS Volumes, ensure Include in database and Enable USN Journal logging are checked for all local fixed drives.
  3. If you use ReFS, ExFAT, or FAT32 drives, navigate to Folders and add those drive paths manually.

Step 3: Enable Keyboard Shortcuts for Instant Access

To turn Everything into a global search launcher:
1. Go to Tools > Options > Options > Keyboard.
2. Set the Toggle window Hotkey to Alt + Space or Win + Shift + F.
3. Now, whenever you need a file, hit your global shortcut, type a query, press Enter, and open your file instantly.
