Architecture & How It Works: The Magic of MFT Indexing

Why is Everything so drastically faster than standard Windows Search? The secret lies in its architectural approach to file indexing.

1. Direct NTFS Master File Table (MFT) Access

Traditional search tools scan directory trees folder by folder, or continuously read document contents to maintain a heavy database. Everything takes a different shortcut on NTFS volumes: it directly reads the Master File Table (MFT).

The MFT is a hidden database file created by the NTFS file system that contains metadata for every file and folder on the volume (name, size, timestamps, permissions, and cluster locations). Because the MFT is sequentially structured, Everything can read the file headers directly from disk bypassing the slow Windows File System API.

2. Real-Time USN Journal Monitoring

Once the initial MFT index is built, Everything monitors the Update Sequence Number (USN) Change Journal. Whenever a file is created, renamed, modified, or deleted, Windows logs the event in the USN Journal. Everything listens to these low-level journal updates and updates its memory index in real time. This ensures search results are always 100% accurate without requiring constant background disk scanning.

Mastering Search Syntax & Operators

While simple queries (e.g., typing report 2026) work immediately, Everything unlocks incredible power through its search syntax. Here is a masterclass in commands you can use today.

Basic Operators & Wildcards

  • * : Matches zero or more characters. Example: *.pdf finds all PDF documents.
  • ? : Matches a single character. Example: img_202? finds img_2020 through img_2029.
  • ! : Boolean NOT operator. Example: project !backup finds files containing "project" but excludes "backup".
  • | : Boolean OR operator. Example: png|jpg finds files with either PNG or JPG in the name.
  • " " : Exact phrase matching. Example: "Quarterly Financial Report".

Advanced Attribute Modifiers

Everything allows filtering by specific file metadata:

# Find files larger than 1 Gigabyte in the Downloads folder
path:C:\Downloads size:>1gb

# Find MP4 video files created or modified in the last 7 days
ext:mp4 dm:last7days

# Find empty folders on drive D:
folder: empty: D:

# Search using Regular Expressions (Regex)
regex:^[0-9]{4}_report\.docx$

Essential Function Reference Table

size:<amount> Filters files by exact or relative byte/KB/MB/GB size size:>500mb or size:empty

Advanced Power Features: Server Plugins, CLI & Remote Indexing

Beyond desktop file searching, Everything includes enterprise-grade utilities that transform how IT managers and developers handle storage architecture.

1. Command-Line Interface (CLI - es.exe)

Voidtools provides a separate command-line tool called ES (Everything Search CLI). With es.exe, developers can query the running Everything index directly from PowerShell, Windows Command Prompt, or custom scripts.

# Find all log files modified today and export to a text file
es.exe ext:log dm:today > C:\Logs\today_logs.txt

This enables lightning-fast file searching inside automated CI/CD pipelines, system maintenance scripts, and backup operations without scanning storage media repeatedly.

2. Built-in HTTP Web Server

Everything includes an integrated HTTP web server. When enabled, you can search and download files hosted on your workstation remotely from any web browser across your local network or VPN.

  • Use Case: Access files on your office desktop from a laptop or mobile phone over Wi-Fi without configuring complex SMB file shares.
  • Security: Supports username/password authentication, custom port configuration, and IP restriction lists.

3. ETP / FTP Server Integration

For multi-device environments or remote branch offices, Everything can run as an ETP (Everything Transfer Protocol) or standard FTP server. A central workstation can index remote file servers instantly, consolidating enterprise-wide file indexing into a single, light application.

Step-by-Step Setup & Best Practices Guide

Follow this setup workflow to optimize Everything on Windows 10 or Windows 11:

Step 1: Installation & Service Setup

  1. Download the latest installer or portable zip from the official site (voidtools.com).
  2. Select Install Everything Service during setup.
    Why? Running the background service allows Everything to read NTFS indexing data without prompting for User Account Control (UAC) elevated administrator permissions every time you launch the application interface.

Step 2: Configure Global Hotkeys

To make file lookup seamless:
1. Open Everything and navigate to Tools > Options > Keyboard.
2. Set Toggle window Hotkey to Ctrl + Alt + Space or Win + Shift + F.
3. Now, whenever you need a file, hit your shortcut key, type the name, hit Enter, and close the window instantly.

Step 3: Exclude System & Temporary Files

Clean up clutter by filtering out unneeded system directories:
1. Go to Tools > Options > Exclude.
2. Add standard junk folders to the Exclude List:
- C:\Windows\Temp
- C:\$Recycle.Bin
- AppData\Local\Temp

Frequently Asked Questions (FAQs)

FAQ 1: Is Voidtools Everything safe to use on Windows 11?

Yes, absolutely. Voidtools Everything is a well-established, highly safe utility used by millions of IT security experts worldwide. It contains no adware, spyware, or bundled third-party bloat. It accesses disk structures using standard read-only Windows system privileges.

FAQ 2: How does Everything index millions of files in under a second?

Instead of traversing folders one by one, Everything directly reads the raw NTFS Master File Table (MFT) structured database from your drive. Because it processes binary file records sequentially straight into memory, it achieves instantaneous index build times.

FAQ 3: Can Everything search inside the contents of files?

Yes, but with a nuance. By using the content: search modifier (e.g., ext:txt content:"secret key"), Everything will search file contents. However, because content is not stored in its permanent RAM index, content searches are slower than file name queries. For heavy text content indexing, combining Everything with dedicated text search tools (like Agent Ransack or Ripgrep) is recommended.

FAQ 4: How do I stop Everything from requiring Administrator permissions on startup?

During installation, choose the option to "Install Everything Service". This runs a lightweight background service with elevated privileges to access MFT records, allowing the main graphical user interface (GUI) to run under standard user permissions without triggering UAC prompts.

FAQ 5: What is the difference between Everything 1.4 and Everything 1.5 Alpha/Beta?

Everything 1.4 is the battle-tested, highly stable public release. Everything 1.5 Alpha/Beta introduces advanced next-gen features, including multi-threaded indexing, enhanced dark mode support, properties indexing (such as audio bitrates, image dimensions, and EXIF data), improved ReFS support, and custom search tab groups.
