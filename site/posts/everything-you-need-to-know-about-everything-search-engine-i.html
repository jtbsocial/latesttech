What is Everything by Voidtools?

Developed by David Carpenter of Voidtools, Everything is a lightweight freeware search utility designed exclusively for Microsoft Windows. Unlike traditional desktop search applications that scan file content line-by-line, Everything focuses specifically on filenames and folder paths.

First released over a decade ago and continually refined through 2026, the utility has achieved cult status among system administrators, software engineers, digital archivists, and power users worldwide. Its minimalist interface conceals unmatched search throughput capable of querying millions of files in mere milliseconds.

How Everything Works: The Secret Behind Its Speed

To understand why Everything feels instantaneous, you must understand how Windows stores file metadata on formatted storage drives.

The NTFS Master File Table (MFT) Bypass

Traditional search utilities crawl your file tree folder by folder, opening directories and requesting file handles from the OS API. This creates heavy read disk I/O and causes immense latency.

Everything takes a radically different route:
1. Direct MFT Parsing: When launched with administrative privileges, Everything bypasses standard Windows APIs and directly reads the Master File Table (MFT) of NTFS volumes.
2. In-Memory File Indexing: It extracts only file and folder names, paths, and attributes, building a lean index entirely in system RAM.
3. USN Change Journal Tracking: To maintain real-time accuracy without re-scanning, Everything monitors the NTFS Update Sequence Number (USN) Change Journal. The second a file is created, modified, or deleted, Windows logs the change in the USN journal, and Everything updates its index instantaneously.

[ File System Event ] ---> [ NTFS USN Journal ] ---> [ Everything RAM Index ] ---> [ Instant UI Update ]

Because file contents are not indexed by default, a clean installation containing 1,000,000 files takes approximately 1 second to index and uses roughly 20-30 MB of RAM.

Key Features & Technical Breakdown

1. Minimalist UI & Low Resource Usage

The graphical interface is clean, uncluttered, and responsive. There are no fancy animations or modern web-view containers taking up memory. It runs as a native Win32 application with near-zero CPU idle consumption.

2. Multi-Language & Modular Extensions

Voidtools offers language packs covering dozens of localized languages, alongside a robust Command-Line Interface (CLI) executable (es.exe) for integration into custom PowerShell scripts, batch automation, or developer workflows.

3. Native Server & Remote Search Support

Need to query file structures on a headless home lab server, network-attached storage (NAS), or remote office machine? Everything includes a built-in HTTP/FTP Server plugin allowing users to perform searches over a secure local web interface or network socket.

4. Deep Content Indexing Options

While legendary for filename matching, newer builds allow optional document property and content indexing (e.g., text inside .txt, .docx, .pdf files) for targeted folders, giving users the choice between raw speed and content depth.

Step-by-Step Installation & Setup (2026)

Setting up Everything is straightforward. Follow these steps for an optimal configuration:

Step 1: Download Official Binaries

Always download from the official Voidtools domain (voidtools.com). Choose between:
* Installer Version (x64): Best for primary desktop setups; includes background service integration.
* Portable Version: Ideal for USB drives, IT troubleshooting toolkits, and portable environments.

Step 2: Configure Service Privileges

During installation, select "Install Everything Service". This enables Everything to read the NTFS MFT in the background without prompting you with User Account Control (UAC) elevation popups every time the program launches.

Step 3: Indexing Scope & Drive Selection

  1. Navigate to Tools -> Options -> NTFS.
  2. Ensure "Automatically index new fixed NTFS volumes" and "Include in database" are checked.
  3. For non-NTFS drives (e.g., FAT32, exFAT external flash drives, or network shares), navigate to Folders and add target paths manually.

Advanced Search Operators & RegEx Mastery

The real power of Everything lies in its rich search query syntax. You can combine operators to narrow down millions of files instantly.

Basic Search Syntax Examples

  • Search by Extension: *.pdf or *.mkv
  • Combine Terms (AND): report 2026 pdf (Finds files containing all three words)
  • OR Operators: photos | pictures (Finds files containing either keyword)
  • Exclude Terms (NOT): project !draft (Finds files with 'project' but excludes 'draft')

### Regex (Regular Expression) Power Queries
Toggle RegEx mode (`Ctrl + R`) or use the `regex:` prefix:
* `regex:^[0-9]{4}_invoice` : Finds files starting with a 4-digit year followed by `_invoice`.
* `regex:(backup|archive).*(2025|2026)` : Finds filenames containing exact terms 'backup' or 'archive' along with years 2025 or 2026.

## Everything Server Plugin & Remote Indexing

For IT professionals managing server fleets or home lab enthusiasts with central media storage, Everything offers server capabilities out of the box.

### HTTP Web Interface Setup
1. Go to `Tools` -> `Options` -> `HTTP Server`.
2. Check **"Enable HTTP Server"**.
3. Assign a custom port (e.g., `8080`) and set an authentication username and password.
4. Access your server's search index from any browser on your local network at `http://localhost:8080`.

### Command-Line Interface (ES.exe)
The command-line interface executable allows scripts to execute queries directly:
```bash
es.exe -ext mp4 -size >500MB -sort date-modified-desc

This outputs matching file lists directly to stdout, perfect for automated cleanup or audit scripts.
