What Exactly Is Everything by voidtools?

Created by David Carpenter under the voidtools moniker, Everything is a desktop search application designed for Microsoft Windows operating systems. Unlike traditional search engines that crawl file contents by default, Everything focuses primarily on indexing file and folder names.

When you open Everything for the first time on a fresh Windows installation containing over one million files, the application builds its initial search index in approximately 1 to 3 seconds. Subsequent searches are displayed in real-time as you type each keystroke.

Under the Hood: How Everything Achieves Blazing Speeds

How does Everything find a single text file among millions in milliseconds while Windows Explorer struggles for minutes?

1. Direct NTFS Master File Table (MFT) Reading

When installed on an NTFS formatted drive, Everything bypasses standard Windows File System APIs. Instead, it reads the Master File Table (MFT) directly from disk memory. The MFT is an internal system database where NTFS stores structural metadata for every file and folder. Because reading the raw MFT requires minimal I/O operations, indexing is nearly instantaneous.

2. USN Journal Tracking

Once the initial MFT index is built, Everything does not constantly re-scan your hard drives. Instead, it monitors the Update Sequence Number (USN) Change Journal maintained by NTFS. When a file is created, modified, renamed, or deleted, Windows logs the event in the USN Journal. Everything simply Listens to these USN change notifications and updates its in-memory database in real-time.

3. In-Memory Search Indexes

Everything maintains its file name index directly in RAM using highly optimized data structures. Because RAM access speeds are orders of magnitude faster than NVMe SSDs or traditional hard drives, live string matching occurs instantaneously as you type.

Core Features Breakdown

Instant As-You-Type Search

Results update dynamically with every letter you type into the search box. There are no search submit buttons or loading bars.

Minimal System Resource Overhead

Unlike background indexing services that chew through battery life and CPU clock cycles, Everything sits idle until invoked. Memory consumption scales predictably at approximately 30-40 MB per million files.

Advanced Regex & Wildcard Support

For software engineers, data analysts, and power users, standard string matching is often insufficient. Everything natively supports full Regular Expressions (Regex) and complex wildcard syntax.

Remote File Access & Web Server

Everything includes a built-in HTTP and FTP server plugin. This allows users to host their local file search database securely across a local network (LAN) or access their home workstation files remotely via any browser.

Command-Line Interface (CLI)

With the es.exe command-line utility, administrators and programmers can query Everything programmatically inside PowerShell scripts or batch files.

The Ultimate Search Syntax Cheat Sheet

Mastering Everything syntax transforms file retrieval into an effortless art form. Here are the most essential operators and modifiers:

1. Basic Filters & Wildcards

  • *.pdf — Finds all PDF files.
  • report 2026 — Finds files containing both "report" and "2026".
  • "sales report" — Finds exact phrase matching "sales report".
  • invoice*.xlsx — Wildcard matching starting with "invoice" ending in .xlsx.

2. Boolean Logic

  • png | jpg — Finds files that are either PNG or JPG (OR operator).
  • !draft — Excludes any file containing the word "draft" (NOT operator).
  • <budget | forecast> 2026 — Grouping query logic.

3. File Type Functions

  • doc: or ext:docx;pdf;rtf — Filter by document file types.
  • pic: — Filter by image extensions (jpg, png, gif, webp, etc.).
  • audio: — Filter by sound files (mp3, flac, wav).
  • zip: — Filter by compressed archives.

4. Size & Date Modifiers

  • size:>1GB — Finds files larger than 1 Gigabyte.
  • dm:today — Finds files modified today.
  • dm:lastweek — Finds files modified within the past week.
  • size:10MB..50MB — Size range filter.

5. Advanced Property Queries

  • dupe: — Identifies duplicate file names.
  • empty: — Finds empty folders or zero-byte files.
  • path:C:\Projects — Limits search results exclusively to C:\Projects directory.

Step-by-Step Setup & Optimization Guide

Getting started with voidtools Everything takes less than two minutes. Follow this optimal configuration guide for maximum performance and security:

Step 1: Download & Installation

  1. Visit the official website at voidtools.com.
  2. Download the lightweight installer (64-bit version recommended for modern Windows PCs).
  3. During installation, select "Install Everything service". This allows Everything to index NTFS volumes without requiring Administrative privilege elevation every time you launch the application UI.

Step 2: Optimal Preferences Configuration

  1. Launch Everything and open Tools > Options (Ctrl + P).
  2. Under General > UI, check "Run in background" and "Show tray icon".
  3. Under NTFS Drives, ensure "Automatically index new fixed NTFS volumes" and "Enable USN Journaling" are checked.
  4. Under Exclusions, add system directories you wish to skip (e.g., $Recycle.Bin, C:\Windows\WinSxS) to keep search result sets pristine.

Step 3: Keyboard Shortcut Mapping

Assigning a global hotkey makes file searching instant from anywhere in Windows:
1. Open Tools > Options > Keyboard.
2. Locate Toggle window hotkey.
3. Set hotkey to Alt + Space or Ctrl + Shift + F.
4. Click Apply.

Now, no matter what program you are working in, pressing your hotkey summons the search bar immediately.

HTTP Web Server Plugin

By enabling the HTTP Server option under Tools > Options > HTTP Server, Everything spins up a ultra-lightweight local web server. You can access your desktop search index from a laptop, smartphone, or tablet on your Wi-Fi network by visiting http://<your-pc-ip>:<port>.

Command-Line Utility (es.exe)

The es.exe executable allows command-line search integration. For example:

es.exe -ext pdf -size > 500MB "2026 Quarter 1"

This command returns all PDF files larger than 500MB containing the phrase "2026 Quarter 1" directly to standard console output, making it ideal for automation scripts.
