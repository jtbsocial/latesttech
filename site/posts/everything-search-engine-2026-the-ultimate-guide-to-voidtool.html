What is Everything by Voidtools?

Everything is a lightweight, freeware search engine utility designed exclusively for Microsoft Windows by David Carpenter of Voidtools. Unlike traditional search utilities that crawl directories file-by-file or build bloated content indexes, Everything focuses on instant filename and folder locating.

When you open Everything for the first time, it indexes fresh installations of Windows in less than a second. Even on drive setups holding over 3,000,000 files, initial indexing rarely takes more than 5 to 10 seconds. Once indexed, file searches occur in real time as you type each letter.

Key Metrics at a Glance:

  • Installer Size: ~1.8 MB
  • Memory Usage: ~12–18 MB RAM for 1,000,000 files
  • Index Creation Time: Under 1 second for 100,000 NTFS files
  • License: 100% Freeware (Personal and Commercial use)

How Everything Achieves Near-Instant Indexing

To understand why Everything feels so incredibly fast, you have to look at how Windows handles NTFS (New Technology File System) drives.

The Magic of the NTFS Master File Table (MFT)

Standard file search programs navigate the file system directory tree sequentially, opening each folder to query child items. Everything bypasses this slow OS file layer completely. Instead, it directly reads the raw Master File Table (MFT) located at the root layer of every NTFS partition.

Because the MFT acts as a structured database containing raw metadata (filenames, creation dates, sizes, attributes) for every file on the volume, Everything can pull millions of records into system memory almost instantaneously.

Real-Time Updates via the USN Change Journal

Once the initial index is loaded into RAM, Everything maintains zero-latency accuracy by subscribing to the Update Sequence Number (USN) Change Journal. Whenever a file is created, modified, renamed, or deleted anywhere on your machine, Windows writes a tiny log entry to the USN Journal. Everything intercepts this event stream in real time and updates its internal index instantly without touching disk sectors.

Core Features & Architecture Overview

Everything is packed with functionality tailored to both everyday users and enterprise sysadmins:

  1. Real-Time As-You-Type Querying: Results update instantly with every keypress.
  2. Minimal Resource Consumption: Extremely low RAM footprint and zero idle CPU usage.
  3. Flexible Indexing Support: Full support for NTFS partitions, FAT32/exFAT formatted drives, mapped network drives, and custom folder inclusions.
  4. HTTP & FTP Server Plugins: Host a web interface to search and download local files remotely across your local network or over secure connections.
  5. Command-Line Interface (es.exe): Execute queries, export file lists, and automate file management via PowerShell or batch scripts.
  6. Exportable File Lists: Save drive snapshots as .efu files to query offline drives without connecting physical hardware.
