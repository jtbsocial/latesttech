The Native Search Crisis in Windows

For over two decades, Microsoft Windows users have endured a frustratingly broken feature: native file search. Whether you are running Windows 10 or the latest 2026 updates of Windows 11, pressing Win + S or typing into the File Explorer search box often leads to infinite loading bars, high CPU utilization, fan noise, and unhelpful internet search suggestions from Bing.

Native Windows Search relies on background content indexing services that frequently fail, corrupt their databases, or skip deeply nested directories. When you need to locate a crucial invoice, a buried system config file, or an archive project from three years ago, waiting minutes for zero results is unacceptable.

Enter Everything by voidtools. Created by developer David Carpenter, Everything is a lightweight freeware desktop search utility for Windows that locates files and folders by name instantly. It discards bloated indexing algorithms in favor of raw file system efficiency, yielding search results in real time as you type.

What is Everything? Architecture & Internal Mechanics

To understand why Everything operates at breathtaking speeds, one must look at how it interacts with the storage subsystem. Most file indexing utilities crawl directories sequentially, opening folders, reading metadata, and building heavy relational databases. Everything takes a fundamentally different approach on NTFS formatted drives.

+-----------------------------------------------------------------------+
|                                                                       |
|  [ NTFS Storage Drive ]                                               |
|         |                                                             |
|         v                                                             |
|  [ Master File Table (MFT) ] <--- Reads directly at startup           |

|  [ RAM Index Memory ] ---------> (~1,000,000 files stored in ~30MB)   |
|         |                                                             |
|         v                                                             |
|  [ Real-Time Updates ] <-------- Monitors NTFS Change Journal (USN)    |
|                                                                       |
+-----------------------------------------------------------------------+

1. Direct NTFS Master File Table (MFT) Parsing

The NTFS file system maintains a hidden structural database called the Master File Table (MFT). The MFT reserves records for every file and folder stored on the volume. Instead of walking through folders one by one, Everything opens a raw handle to the MFT on startup, parses the file name metadata in a single linear pass, and loads the basic structure into system memory.

2. NTFS Change Journal (USN) Monitoring

Once the initial memory index is built (which takes roughly 0.5 to 1 second for a fresh drive containing 1,000,000 entries), Everything stays updated without re-scanning your hard drives. It attaches a listener to the NTFS Update Sequence Number (USN) Change Journal. Whenever a file is created, renamed, modified, or deleted, Windows logs the event in the USN journal. Everything intercepts this stream and updates its in-memory index instantaneously.

3. Minimal System Overhead

Because the index stores only file names, path offsets, and basic file attributes in RAM, memory consumption is microscopic. A storage layout with one million files requires only about 30 MB to 45 MB of RAM. CPU usage remains at 0% until a user actively types a query.

Core Features & 2026 Capabilities

While the primary goal of Everything is instant file lookup, the software offers a robust suite of advanced utilities tailored for system administrators, developers, content creators, and daily power users.

  • Instant As-You-Type Search: Search queries update the result pane instantly with zero input lag.
  • Command-Line Interface (CLI): Full support for command-line options (ES.exe), enabling automated scripting, PowerShell batch jobs, and headless server environments.
  • HTTP and FTP Server Integration: Built-in web server capabilities allow you to host your file index over a local network or secure VPN. Authorized devices can search and download files via a web browser without third-party server tools.
  • Multi-Language Support & Portability: Available as a standard installer or a portable executable that runs directly from a USB flash drive without touching system registries.
  • Custom Filters & Bookmarks: Users can create custom search views (e.g., Audio, Executables, Documents, Pictures, or Large Files) and save complex search strings as one-click bookmarks.
  • Content Searching: While optimized for file names, Everything can perform on-demand string searches inside text, source code, and document files using the content: parameter.
